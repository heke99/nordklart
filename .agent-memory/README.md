# Nordklart agentminne

Detta är projektets komprimerade, versionsstyrda arbetsminne. Läs i ordning:

1. `current-state.md`
2. `open-blockers.md`
3. `next-actions.md`
4. relevanta domänfiler

Regler:

- Källkod, migrationer och tester är sanningskällor. Minnet beskriver dem men ersätter dem inte.
- Uppdatera `current-state.md`, `completed-work.md`, `open-blockers.md`,
  `next-actions.md` och `session-log.md` efter ett materiellt arbetspass.
- Flytta inaktuella historiska statusbilder till `archive/`; blanda dem inte med
  aktuella blockerare.
- Skriv aldrig att något är verifierat utan att ange hur det verifierades.
