# Ordlista

- **Tenant**: ett företag vars data ska vara isolerad.
- **Grant**: tidsbegränsad eller administrativ kommersiell åtkomst.
- **Entitlement/featureåtkomst**: kanoniskt beslut om en specifik funktion.
- **Full Access**: kompletterande åtkomst till funktionskatalogen, exklusive
  separat Bankgiro-tillägg.
- **Engångsköp**: periodbundet köp för exempelvis exakt bokslutsperiod.
- **Resolver**: auktoritativ funktion som sammanväger plan, grant och undantag.
- **RLS**: PostgreSQL Row Level Security.
- **pg-real**: tester mot riktig PostgreSQL, inte endast mocks.
- **Öre**: heltalsenheten för monetära beräkningar.
