# UX och designsystem

- Svenska texter ska beskriva den faktiska systemstatusen.
- Tekniska åtkomstfel visar återförsök/support, inte köp-CTA.
- Funktioner ska vara nåbara via sammanhängande navigation och skyddade routes.
- Tillstånd för laddning, tomt resultat, fel, read-only och nekad operation ska
  vara separata.
- Återanvänd befintliga tokens och komponenter; skapa inte lokala visuella
  parallellsystem.
