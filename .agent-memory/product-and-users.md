# Produkt och användare

Primära användare:

- Företagare som sköter löpande bokföring och fakturering.
- Ekonomiansvariga och löneadministratörer.
- Redovisningsbyråer som arbetar i flera kundföretag.
- Revisorer och andra läsande/granskande roller.
- Plattformspersonal med uttryckligt, granskningsbart stödbehov.

Produkten måste förena enkel svensk UX med strikt ekonomisk spårbarhet. Ett
tekniskt fel får aldrig presenteras som att kunden behöver köpa eller uppgradera
en produkt.
