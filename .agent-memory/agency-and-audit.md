# Byrå och revision

- Byråanvändare ska bara se företag med verifierad relation och rätt operation.
- Massoperationer måste auktorisera varje företag, inte bara byråkontot.
- Revision kräver oföränderlig eller tydligt versionsförd historik för ekonomiska
  mutationer, åtkomständringar och bokslutshändelser.
- Auditposter ska ange aktör, företag, operation, mål, tid och resultat utan att
  logga hemligheter.
