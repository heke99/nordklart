# Bank och partners

- Bankgiro är ett separat tillägg och ingår inte automatiskt i Full Access.
- Bankgiro-UI och API ska skilja verkligt tilläggskrav från tekniskt resolverfel.
- Bank- och betalningsflöden kräver idempotens, externa referenser och tydlig
  avstämningsstatus.
- Partnerwebhooks ska signaturverifieras och kunna återspelas säkert.
