# Integrationer

Aktiverade extension-definitioner i genererat register:

- `enable-banking`
- `email`
- `nordklart-migration`
- `tic`
- `mcp-server`
- `cloud-backup`
- `skatteverket`
- `invoice-inbox`
- `document-extraction`

Integrationer ska ha explicit ägare, validerad konfiguration, timeout,
återförsök/idempotens där lämpligt samt loggning utan hemligheter. Genererat
register ska uppdateras med projektets generator, inte handredigeras.
