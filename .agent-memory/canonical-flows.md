# Kanoniska flöden

## Skyddad mutation

Autentisering och MFA → tenant/medlemskap → operation/RBAC → featureåtkomst →
validering → domäntjänst/RPC → audit/logg → stabilt API-svar.

## Bokföring

Utkast/importunderlag → validering och kontoresolver → balanserade rader i öre →
kanonisk commit → lås- och periodsäkerhet → rapportprojektion.

## Bokslut

Företagsåtkomst eller giltigt periodbundet engångsköp → readiness/blockers →
beräkning → kanonisk stängningskörning → rapporter/årsredovisning → signering.

Lokala genvägar som hoppar över ett steg är inte nya kanoniska flöden.
