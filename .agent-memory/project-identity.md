# Projektidentitet

Nordklart är en svensk flerbolagsplattform för bokföring, fakturering, lön,
rapportering, dokument, byråarbete och årsbokslut.

- Runtime: Next.js 16.2.9, React 19.2.3 och strikt TypeScript 5.9.
- Databas och identitet: Supabase/PostgreSQL med RLS och SQL-migrationer.
- Monetära värden lagras och beräknas i öre.
- Språk och regulatorisk kontext: svenska företag, BAS-konton, moms, SIE och
  svenska bokslutsflöden.
- Den mottagna källkodsarkiven saknade Git-metadata; ändringsjämförelser i detta
  arbetspass görs mot en orörd kopia av samma arkiv.
