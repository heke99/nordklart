# Nordklart

Nordklart är en proprietär svensk SaaS-plattform för bokföring, bankautomation, bokslut, redovisningsbyråer och rapportering.

## Produktmål

Nordklart ska kombinera strikt svensk bokföringslogik med enkel användning:

- dubbel bokföring med balanserad debet/kredit
- BAS-kontoplan, moms, resultat, balans, huvudbok och SIE
- bokslut och bokslutsunderlag
- multi-tenant SaaS med bolag, byråer och klientbolag
- bankintegration och kontrollerad automatisk bokföring
- API och webhooks för integrationer
- separat onboarding för Bankgiro/Autogiro via betalpartner

## Viktiga principer

- Bokföringsregler får inte förenklas bort av UI eller automation.
- Låsta perioder korrigeras med rättningsverifikation, inte tysta ändringar.
- All automation ska vara spårbar med regel, confidence och audit.
- Byrå- och klientdata ska vara tenant-isolerad.
- Superadmin styr plattform, byråer, bolag och framtida prisplaner.
